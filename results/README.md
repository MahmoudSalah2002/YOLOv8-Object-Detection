# Model Training Results

This folder contains the evaluation results and visualizations generated during YOLOv8 model training.

## Results Included

- `results.png` — Training and validation metrics over epochs.
- `confusion_matrix.png` — Confusion matrix for model evaluation.
- `confusion_matrix_normalized.png` — Normalized confusion matrix.
- `BoxF1_curve.png` — F1 score curve.
- `BoxP_curve.png` — Precision curve.
- `BoxPR_curve.png` — Precision-Recall curve.
- `BoxR_curve.png` — Recall curve.

## Model Weights

The trained model weights (`best.pt` and `last.pt`) are saved in the training output directory.

## Notes

These files help evaluate the model's performance on cat and dog detection tasks.
